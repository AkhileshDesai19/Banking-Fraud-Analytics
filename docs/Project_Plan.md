# Banking Fraud & Customer Risk Analytics

## Business Problem
Banks process millions of daily transactions.
Management needs an automated analytics platform to identify fraud trends, high-risk customers, and operational KPIs.

## Objective
Build an end-to-end cloud-based analytics pipeline using AWS S3, Python ETL, PostgreSQL, SQL, and Power BI.

## Tech Stack
- AWS S3
- Python
- PostgreSQL
- SQL
- Power BI
- GitHub

## Expected Outcome
A production-style analytics solution that automates data ingestion, transformation, analysis, and dashboarding.
